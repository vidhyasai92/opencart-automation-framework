═══════════════════════════════════════════════════════════════════════════
  📝 WHAT EACH COMMAND MEANS
═══════════════════════════════════════════════════════════════════════════

cd ~/eclipse-workspace/java-practice/Opencart100
→ Go to your project folder (like opening a folder on your computer)

git remote add origin https://github.com/USERNAME/REPO.git
→ Tell git where the online storage is (like saving a bookmark)
→ "origin" is just a nickname for the long URL

git branch -M main
→ Rename your branch from "master" to "main" (GitHub's new standard)
→ Think of it as: Renaming a folder

git push -u origin main
→ Upload your code to GitHub (like uploading files to Google Drive)
→ "-u" means: Remember this for next time
